# BoAI 路线图

> 一个本地优先的个人 AI 管理器。先把 Skills 管理做好，再逐步扩展到其他 AI 资产。

## 现在：Skills Manager MVP

- 统一查看全局、Workspace 与项目中的 Skills，不隐藏同名或多位置副本。
- 展示已安装、我的 Skills 与使用统计，让本机资产状态一目了然。
- 持续完善 Skill 的发现、详情、创建和 Agent 使用体验。

## 接下来：安全管理闭环

- 记录 Skill 的来源、版本、内容哈希与操作历史。
- 支持安装、更新 Diff、安全卸载、备份与恢复。
- 明确显示 Skill 在哪个 Agent、Workspace 或项目中生效。

## 以后：个人 AI 资产中心

- 管理 Tools、Plugins、MCP、Hooks、Commands 与 Permissions。
- 建立可查看、可编辑、可删除的 Knowledge 与 Memory。
- 通过 Profile 和 Injection Plan，把能力安全地交给不同 Agent 使用。

## BoAI 的原则

**文件可见 · 来源可追溯 · 修改可预览 · 操作可恢复 · 作用域明确**

路线图表达产品方向，不承诺固定日期；实际进度以可用、可验证的交付为准。
