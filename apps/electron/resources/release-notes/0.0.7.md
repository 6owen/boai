# BoAI 0.0.7

## Features

- **技能分组**：可以在“自己”中创建、重命名和删除分组，并从每个技能的操作菜单将技能移动到对应分组。

## Improvements

- **更轻量的桌面安装包**：精简构建资源与语言包，改用 Electron 内置的 Node.js 运行 PI，并移除随桌面应用附带的 Bun 与 Claude Agent SDK runtime。
- **统一 PI Agent 内核**：聊天、工具调用和模型供应商连接统一通过 PI Backend 运行；Anthropic API Key 和 Claude 模型仍可作为 PI 的上游模型使用。

## Bug Fixes

- **修复无效的 Windows shell 配置**：自定义 Git Bash 路径现在会传递给 PI 子进程，不再写入已经移除的 Claude Code 环境变量。

## Breaking Changes

- **移除 Claude Code Backend 与订阅登录**：Claude Pro / Max OAuth、Claude Agent SDK 和旧 Claude Backend 已移除。此版本不迁移旧 Claude Backend 会话或订阅凭据。
