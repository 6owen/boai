# BoAI 0.0.11

## Features

## Improvements

- **多 Agent Skills 发现**：技能页现在会读取 Codex、Claude、Cursor 等已知 Agent 的本地技能目录，并显示实际来源。
- **外部技能只读保护**：从其他 Agent 目录发现的技能可以查看和使用，但不会在 BoAI 中被误编辑、更新或删除。

## Bug Fixes

- **Windows 本地 Skills 扫描**：无需安装 `skills` CLI，也能发现 `%USERPROFILE%` 下 Agent 目录中的技能。
- **Windows 目录链接兼容**：扫描器现在支持技能目录使用符号链接或 Windows junction。
