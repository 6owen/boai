# BoAI 0.0.10

## Features

## Improvements

- **Windows 安装路径可选**：安装向导现在支持选择 BoAI 的安装目录，不再直接静默安装到默认位置。
- **Windows 原生应用图标**：快捷方式、任务栏和开始菜单现在使用针对 Windows 缩放优化的多尺寸图标。

## Bug Fixes

- **Windows Git 检测**：启动时会刷新图形应用继承的 PATH，并支持检测自定义安装目录中的 Git 和 Git Bash。
- **BoAI 安装包标识**：新安装包和更新缓存使用 BoAI 名称，不再生成旧的 `craft-agentelectron` 路径。
